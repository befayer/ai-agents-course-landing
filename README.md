# Лендинг курса «Разработка ПО с AI-агентами»

Spring АйО Академия × OpenIDE. Старт 1 декабря 2026.

Статичная страница: один `index.html` (стили и скрипты внутри) и папка `assets/`. Сборка и зависимости не нужны.

## Состав

```
index.html                  страница
assets/spring-aio-logo.svg  логотип Spring АйО
assets/openide-logo.svg     логотип OpenIDE
assets/ilya-kuchmin.jpg     фото лектора
assets/leaf-bullet.png      аватар группы в макете чата
```

## Как запустить локально

Из папки проекта:

```bash
python3 -m http.server 8080
```

Открыть http://localhost:8080

Подойдёт любой статический сервер (`npx serve`, nginx, Caddy). Можно открыть `index.html` двойным кликом — всё заработает, но через сервер надёжнее.

## Как выложить

Залить содержимое папки как есть на любой статический хостинг или в nginx (`root` → эта папка). Пути к файлам относительные, страница работает из любого подкаталога.

## Внешние зависимости

- Шрифты Unbounded и Golos Text грузятся с Google Fonts. Без интернета страница откроется на системных шрифтах. Если Google Fonts недоступен у аудитории, шрифты стоит положить локально в `assets/fonts/` и заменить `<link>` в `<head>` на `@font-face`.
- Больше ничего внешнего нет: ни библиотек, ни аналитики, ни счётчиков.

## Что нужно доделать перед публикацией

1. **Оплата.** Кнопки «Записаться на курс» сейчас ведут к блоку цены (`href="#price"`). Кнопку в карточке «для себя · физлица» нужно направить на ссылку оплаты ЮKassa, когда она будет готова.
2. **Заявка от компаний.** Кнопка «Обсудить обучение команды» ведёт на `#teams` — нужна форма, почта или ссылка на контакт.
3. **Скидка за пилот OpenIDE.** В калькуляторе для компаний она применяется при любом размере группы (50 000 → 45 000 ₽ за место). Если она действует только от 10 человек, поправить строку `if(pilot.checked)per-=5000` в скрипте внизу страницы.
4. **Метатеги для соцсетей** (`og:title`, `og:image`) и favicon не добавлены.

## Поведение страницы

- Анимации первого экрана и финала — canvas, останавливаются, когда блок не виден.
- При включённой в системе настройке «уменьшить движение» анимации отключаются, страница показывается статично.
- Вёрстка проверена на ширине 1440 и 375 px.
